# CompBot
Competition Bot Command Collection for [OA Robot](https://oarobot.com), built for Excel Esports cases.

[CompBot Readme](https://github.com/JaqK23/CompBot/blob/main/CompBot.xlsm%20README/CompBot.xlsm%20README.md): every command and lambda definition, generated from the workbook.

**CompBot Tutorial.xlsx**: a lesson for every command and every lambda, with demo sheets to run them on. Open it and start on the Start here sheet.

Found a ~~bug~~ feature or have an idea? [Report it here](https://github.com/JaqK23/CompBot/issues/new/choose).

Updating replaces CompBot.xlsm. Your own lambdas live in your own library file (Set Lambda Library), so an update never overwrites them.

## Two editions, which one do I want?

- **CompBot** (this folder): for everyone, including competition machines. Sync from `CompBot.xlsm` here.
- **[CompBot Insider](Insider/README.md)**: everything in CompBot plus commands that need Excel features
  most machines do not have yet, starting with in-cell arrays (the Alves Method, by Fredson Alves). Needs
  the Microsoft 365 Insider Beta Channel. Register one edition at a time.
